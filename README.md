# Calculatrice-web
🧮 Calculatrice Web

Une calculatrice moderne développée en HTML, CSS et JavaScript.

Fonctionnalités

- Addition
- Soustraction
- Multiplication
- Division
- Effacement de l'écran
- Suppression du dernier caractère
- Interface simple et responsive

Technologies utilisées

- HTML5
- CSS3
- JavaScript

Structure du projet

calculatrice-web/
├── index.html
├── style.css
├── script.js
└── README.md

Installation

1. Télécharger ou cloner le projet.
2. Ouvrir le fichier index.html dans un navigateur.
3. Utiliser la calculatrice.
